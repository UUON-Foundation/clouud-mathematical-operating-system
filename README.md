# Clouud Application

Structured intelligence engine with autonomous decision-making and lattice services.

## Features

- Autonomous decision-making (C engine)
- Lattice-based reasoning
- Real-time analytics
- Multi-chain integration
- Pattern extraction

## Quick Start

```bash
npm install
npm run dev
```

API runs on http://localhost:3000

## Environment

```bash
DATABASE_URL=postgresql://...
ANTHROPIC_API_KEY=sk-ant-...
PORT=3000
```
